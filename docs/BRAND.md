海报已经画好了（`docs/media/poster.jpg`）：暗房里的模拟面试——镜头前是**逆光剪影**
的候选人，右上角是带琥珀声波的**几何化 AI 面试官**，右下角是叠着的**评估报告卡片**
（柱状图 + 雷达图）。

下面这段提示词是**重画用的存档**——要改风格就照着它再来一张，别从零描述：

```text
一张 16:9 的深色科技风宣传横幅海报（2400×1350 px），主题是「AI 模拟面试」。

画面构成（从左到右）：
左侧三分之一：一块深色圆角矩形面板，像一个视频会议的舞台缩略图。
  面板里是一个**抽象的人物剪影**（只看得出头肩轮廓，看不出五官），
```

## 流程图 · 提示词（定稿稿的来路）

`docs/media/flow.jpg` 是**画出来的**——下面那段提示词就是它的来路。
README 里「简历 + JD → 四步」那一段现在用的是这张图，不再是 mermaid 代码块。

**为什么用图不用 mermaid**：npm 包页（`npm view dsh-realtime-interview` 的那个页面，
也是插件的落地页）**不渲染 mermaid**，读者会看到一坨代码；GitHub 移动端也不保证渲染。
图在哪都成立，代码块只在 GitHub 桌面端成立。

**为什么不用霓虹**：DESIGN.md §0 已经把话说明了——
「素雅但高级：中性墨底 / 纸白 + 单一蓝灰强调色；**不要**彩色渐变、霓虹、
玻璃拟态堆叠、发光边框」。头一版出的是饱和的青紫蓝霓虹渐变 + 发光外框 + 粒子点阵 +
多层渐变圆环，和上面那张 `poster.jpg`（墨底 + 琥珀 + 蓝灰、哑光）**不是同一套设计
语言**。README 是门面：**门面和产品必须是同一套设计**，否则门面越漂亮，越像在卖
另一个产品。所以按下面的提示词重画了一版——**版式沿用，肤色换掉**。

### 提示词（可直接贴）

```text
一张 16:9 的深色科技风**流程图横幅**（2400×1350 px），主题是「AI 模拟面试的四步流程」。

整体气质：一间安静的暗房里的一条**流程卡带**。哑光纸面 + 极低对比的玻璃感卡片，
像一台设备的 UI 被放大了，而不是一张赛博朋克海报。

画面构成（从上到下、从左到右）：

顶部正中：一枚**横向胶囊卡**（全圆角，宽度约画面 26%，高度约画面 9%）。
  卡面比背景亮一档（墨蓝灰），边缘一圈 1px 冷灰描边，
  **顶部一道极细的白色内高光**（像被光从上方擦过），底部一道极淡的暗边。
  卡内从左到右：一个单色线稿的「简历文档」小图标、一个加号、
  一个单色线稿的「公文包」小图标、一条 1px 竖直细分隔线、
  右侧一组较粗的中文标题。
  胶囊**不要**发光描边，**不要**渐变填充。

一条 1px 细线从胶囊底部向下伸出，再折向左侧的第一张卡片，形成安静的折线连接。

中部：一排**四张等宽等高的卡片**（圆角 20），卡片之间留均匀间距，
卡片之间用一条极细的箭头线相连（冷灰色，末端一个小箭头，不发光）。
四张卡片从左到右的内容：

  卡片一：单色线稿图标——一张带放大镜的文档，旁边一张打勾的清单；
  卡片二：单色线稿图标——两个对话气泡 + 一个人的头肩轮廓；
  卡片三：单色线稿图标——一台摄像机 + 一支麦克风，旁边一个极小的红色圆点；
  卡片四：单色线稿图标——一张报告卡片（上面有柱状图）+ 一个小对勾徽章。

每张卡片的版式完全一致（自上而下）：
  顶部左侧：一枚小圆牌（直径约画面 3.4%），圆牌里是编号 ①②③④，冷灰蓝色；
  中部：线稿图标（高度约画面 5%），单色细描边，冷灰蓝；
  图标下方：一条 1px 细分隔线；
  再下方：卡片标题（中文，纸白骨色，中等字重）；
  标题下：三行描述文字（中文，灰白色，行距宽松）。

卡片质感：表面比背景亮一档，左上到右下有一道**极低对比的斜向镜面高光**，
顶边一道 1px 白色内高光，底边一道暗边；外侧一圈 1px 极淡的冷灰描边，
下方一层大而柔的**蓝黑色**环境影（不要纯黑阴影）。卡片看起来是**浮起**的。

画面底部：一条极淡的椭圆形台面轮廓（像一张观片台的台沿），
只有一道若有若无的琥珀色边光。不要发光圆环，不要多层圆环。

配色（严格只用这几支，别的一律不许）：
  墨底 #04060A → #0F1319（背景，顶部略亮）
  卡片面 #171D25
  纸白骨 #EBEDF0（卡片标题）
  灰白 #A9AFB9（描述文字）
  冷灰蓝 #7FA6D9（结构色：编号圆牌、图标、连线、描边）
  琥珀 #CDA96F（唯一的暖色，只用在台面边光与极少量点缀）
  朱红 #E0563F（只给 REC 那一个几像素的小圆点）
  分隔线 rgba(255,255,255,0.115)

质感：哑光纸面 + 极低对比的玻璃感卡片。**不要**霓虹、赛博朋克、镜头光斑、
粒子特效、渐变彩虹、饱和的青紫品红、发光外框、多层渐变圆环、扫描线、HUD 装饰。
整体像「一间安静的暗房里的一场面试」。

不要出现：任何真实人脸、任何现成品牌 logo、任何水印、任何英文单词、
任何中文文字（画面是纯图形，文字后期自己排；文案见下）。
```

### 文案（后期自己排）

模型渲染中文常出错字。**除非你的工具中文渲染可靠**，否则按下面的表自己排：

| 位置 | 文字 | 排版 |
|---|---|---|
| 顶部胶囊 | `简历 + JD` | 一行，字号 = 卡片标题的 1.15 倍 |
| 卡片一标题 | `① 准备底稿` | 一行，纸白骨；圆牌里只放数字「1」，标题别再带圈号 |
| 卡片一描述 | `助手读 JD、拆岗位要求`<br>`映射你的经历`<br>`落一份分级考点清单` | 三行，灰白 |
| 卡片二标题 | `② 逐轮面试` | 一行，纸白骨 |
| 卡片二描述 | `按清单提问`<br>`按你的回答追问`<br>`你说的每一句都进转录` | 三行，灰白 |
| 卡片三标题 | `③ 实时摄像与语音` | 一行，纸白骨 |
| 卡片三描述 | `摄像头画面、麦克风转写`<br>`问题朗读`<br>`整场连续录制` | 三行，灰白 |
| 卡片四标题 | `④ 事后报告` | 一行，纸白骨 |
| 卡片四描述 | `逐考点评估`<br>`亮点与风险点`<br>`清单调整回顾、改进建议` | 三行，灰白 |

**字号**（这条最容易翻车）：描述文字的字高约等于**画布宽度的 1/60**
（2400 宽的画布里约 40 px，压到 1600 宽后约 27 px，README 里显示约 14 px）。
再小就只剩「知道有张图」，读不出内容。

**定稿这一版实际怎么排的**：出图时中文渲染没问题，但模型自己拟了标题——
「简历分析 / 模拟对话 / 视频面试 / 评估报告」。那是**通用说法，不是这个产品的说法**
（这个插件的第一步是**准备底稿**，不是「分析简历」）。图与文必须用同一套词，
否则读者会以为是两套流程。所以四个卡片标题是**出图后重排**的：
按行在卡片表面做线性插值补回被字盖住的背景，再用
`C:\Windows\Fonts\NotoSansSC-VF.ttf`（weight 700、字号 33 px）写回卡片中心；
量旧字的包围盒（4 字标题 131×31 px），新字体要量到同样的宽高。
胶囊标题（「AI 模拟面试的四步流程」）与卡片描述保留原样。

## README 徽标

README 顶部那排徽标现在是这样（`shields.io` + 官方徽章，GitHub 与 npm 都能渲染）：

| 徽标 | 指向 |
|---|---|

| Awesome DSH Plugin | awesome-dsh-plugin.com |

`Awesome DSH Plugin` 那枚要等插件**被收录进 awesome-dsh-plugin** 之后才有意义
（见 `docs/MARKET.md`）。在那之前它指向的页面里还没有这个条目——可以先留着，
