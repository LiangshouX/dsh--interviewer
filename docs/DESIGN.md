# DESIGN.md — 界面契约（这一版的设计宪法）

> 这一份是**实现契约**，不是灵感板。里面出现的每个变量名、类名、组件签名，
> 都是并行开发时各方必须照抄的公共语言。
>
> 三件事一起做：**视觉（素雅但高级）**、**语音配置闭环**、**去说明小字**。
> 视觉细节可以争，下面这些**不许各自发明**：token 名、类名、字号档位、
> 组件签名、文案纪律、验收闸门。

---

## 0. 审美立场

一句话：**这是一间暗房里的观片台，不是一块后台面板。**

| 要 | 不要 |
|---|---|
| 素雅但高级：中性墨底 / 纸白 + 单一蓝灰强调色 | 彩色渐变、霓虹、玻璃拟态堆叠、发光边框 |
| 立体感来自**光**（顶边内高光 + 多层柔和阴影 + 极淡噪点） | 立体感来自粗描边、大投影、拟物按钮 |
| 科技感来自**仪表语言**（等宽小标签、点阵、带刻度的电平、tabular 数字） | 科技感来自赛博网格、扫描线、HUD 装饰 |
| 灵动感来自**位移与呼吸**（入场错峰 40ms、悬停 1px、光斑 46s 漂移） | 灵动感来自弹跳、旋转、闪烁 |
| 品牌感来自**一个记号 + 一致的排版节奏** | 品牌感来自到处放 logo |
| 每个屏幕一句话说得清在干什么 | 每个屏幕一段话解释为什么这样设计 |

**反例（这一版要消灭的）**：「简历存一次，之后每场直接选」「列表会按岗位分组——同一个
岗位的几场聚在一起」「底稿共 14 项，已问 5 项。面试中助手按它动态深挖——具体题目你
看不到，那才是真实面试的样子」。这些是**设计说明书**，不是界面。

## 1. 文案纪律（第三条需求，优先级最高）

一个优秀的产品**不需要解释自己**。所以：

### 硬规则

1. **常驻界面只允许四类文字**：标签（名词）、状态（形容词/数值）、动作（动词）、
   失败时的出路。
2. **每个卡片最多一条提示行**，且必须是下面两种之一：
   - **失败/受限的原因 + 现在能做什么**（`AGENTS.md §7` 的红线，不许删）；
   - **当前状态的来源**（例如「凭据来自宿主的 XIAOMI_TOKEN_PLAN_CN_API_KEY」）。
3. **解释「为什么这样设计」的文字**一律移出常驻界面：进 `title=` 悬停、
   进 `?` 弹层、或删掉。
4. **成功态不写解释**。保存成功 → 「已保存」两个字，不写「下次操作就会按新设置执行」。
5. **空状态给动作，不给说明书**。空简历卡片 = 一个大方框 + 一句「拖入或选择文件」，
   不是一段「还没存过简历。归档简历后按『存进简历库』，以后新建面试就不用再传了」。
6. **同一个信息不写两遍**。标题已经说了「报告」，卡片里就不再写「评估表」。
7. **中文不用书名号+引号堆叠，不用感叹号**。状态句用句号或直接无标点。

### 允许保留的长文本（唯二例外）

- **报告正文**（Markdown 渲染，阅读型内容）；
- **失败诊断**（`diagnostics`、`attempts`、`hint`）——用户排查时必须看得见。

## 2. 排版

字体栈（`30-theme.js` 的 `F`）：

```js
F = {
  // 展示：拉丁衬线 + 中文思源宋（本机已装 Noto Serif SC）。
  // 顺序很关键：Georgia 没有中文字形，中文自然落到 Noto Serif SC。
  display: '"Iowan Old Style", "Palatino Linotype", Palatino, Georgia, "Noto Serif SC", "Source Han Serif SC", "Noto Serif CJK SC", "Songti SC", serif',
  ui:      'system-ui, -apple-system, "Segoe UI Variable Text", "Segoe UI", "PingFang SC", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif',
  mono:    '"SF Mono", "Cascadia Mono", "Cascadia Code", Consolas, "Roboto Mono", ui-monospace, monospace',
}
```

**字号只允许这六档**（其它值出现即为回归）：

| 名字 | 值 | 用途 |
|---|---|---|
| `display` | 24 / 600 / lh 1.26 / ls .01em | 页面主标题、报告大标题 |
| `title` | 17 / 600 / lh 1.45 | 卡片标题、面试官提问 |
| `body` | 13.5 / 400 / lh 1.78 | 正文、转录 |
| `sub` | 12.5 / 400 / lh 1.72 | 次要信息、提示行（**唯一允许的提示字号**） |
| `meta` | 10.5 mono / ls .14em / up | 眉标、路径、计数、时间 |
| `nano` | 9.5 mono / ls .12em | 电平、峰值、极小状态 |

数字一律 `font-variant-numeric: tabular-nums`（类 `.iv-nums`）。
**禁止** 11 / 11.5 / 12 / 12.5 / 13 / 13.5 之外的中间字号（旧的 11/11.5 要并到 `sub` 或 `meta`）。

## 3. 间距 / 圆角 / 描边

- 间距阶梯：`4, 8, 12, 16, 20, 24, 28, 40`（`S.space(n)` 直取，禁止 5/7/9/11/13）。
- 圆角：`sm 10 / md 14 / lg 20 / xl 26 / pill 999`（`S.radius`）。
- 描边只有两级：`--iv-rule`（可见分隔）与 `--iv-rule-soft`（内部细分隔）。
  **不许**再出现 `rgba(...)` 手写描边。

## 4. 材质与层次（立体感）

**立体感不是描边粗细的问题，是「光 + 距离 + 凸凹」三件事。** 每一层表面都要能回答：

| 问题 | 手段 |
|---|---|
| 它朝哪受光？ | 顶部内高光 `--iv-hi` + **左上斜向镜面高光带**（surface 渐变第一层）+ 底部内暗边 `--iv-lo` |
| 它离台面多高？ | **四级 elevation**，每级 = 接触影（1–2px）+ **外缝**（`0 0 0 1px` 深色）+ 环境影（大模糊负扩散）。影是**蓝黑**（`rgba(2,4,9,…)`），不是纯黑 |
| 它是凸起还是凹陷？ | 凸：`.iv-s1/.iv-s2/.iv-s3`；凹：`.iv-well` + `--iv-inset`（输入框、页签槽、电平表底） |

```css
.iv-s1   /* 纸面：内容卡片          elevation-1 */
.iv-s2   /* 浮起：右栏、工具栏、输入区 elevation-2 */
.iv-s3   /* 舞台/侧槽：最深          elevation-3 */
.iv-well /* 凹面：槽、表底            --iv-inset */
```

**凸与凹必须同框**：只有凸起的面板看起来像贴纸，只有凹陷的槽看起来像破洞。
面板里永远同时有两者（卡片浮起、输入框挖进去），层次才可信。

主按钮是**一枚键**：`--iv-primary-top` → `--iv-primary-bottom` 的竖向渐变 +
顶部高光 + 接触影；按下时改为**内阴影**（`button:active`），是真的按下去。

背景：环境光漂移 + 24px 点阵（`.iv-grid`，径向遮罩淡出）+ **暗角**
（`--iv-vignette`，四角收光，让整块面板读成「一台设备」而不是「一张铺开的纸」）。

噪点：`.iv-grain` 用 SVG feTurbulence data-URI 铺满，`opacity: .06`、
`mix-blend-mode: overlay`。只在表面之上用，别铺在文字容器里。

## 5. 动效

全部走 `--iv-ease: cubic-bezier(.2,.8,.2,1)`，全部尊重 `prefers-reduced-motion`（已有全局兜底）。

| 名字 | 效果 | 用在哪 |
|---|---|---|
| `.iv-enter` | `ivRise 320ms`，`animation-delay: calc(var(--iv-i,0) * 40ms)` | 卡片、列表项首次挂载（最多错峰 8 个） |
| `.iv-hover` | 悬停 `translateY(-1px)` + 描边提亮 | 可点卡片、按钮 |
| `.iv-press` | 按下 `scale(.985)` | 按钮 |
| `.iv-sweep` | 悬停时一道 220ms 高光扫过 | 主按钮（唯一允许 sweep 的元素） |
| `.iv-breathe` | 6s 缓慢呼吸（透明度 .5→.85） | 未接通舞台的环、REC 灯 |

**不许**给数据流元素（转录行、电平柱）加入场动画——它们每 1.5 秒就可能重置，
动画会让「安静」变成「乱闪」。这一条比好看重要。

## 6. 颜色纪律（不变）

- 中性墨底/纸白 + 单一蓝灰 `--iv-accent`（链接与聚焦环）。
- 朱红 `tally` **只**给 REC / 危险动作；琥珀 `amber` **只**给“当前提问”；
  青玉 `jade` **只**表示就绪/已完成。
- 主按钮用高对比中性色（暗色骨白、亮色墨色），**不用**品牌色实心填充。

## 7. 组件契约（`70-primitives.js`）

已存在的**不许改签名**（`Section` / `Field` / `Area` / `Disclosure` /
`ChecklistRow` / `Tally` / `ClockBadge` / `SegmentedMeter` / `Markdown` /
`statTile` / `GuardDialog`）——只许改实现与观感。**新增**这些：

```js
// 通用容器：把卡片从"一个 div 带边框"升级成有层次的表面。
Panel({ tone?: 'plain'|'raised'|'stage', pad?: number, style?, children })

// 一行宁静的提示。**全页每屏最多两条。**
Quiet({ children, tone?: 'muted'|'warn', title?: string })   // tone 只管颜色，不是警告框

// 等宽小标签（眉标/计数/单位）。
Meta({ children, tone?: 'faint'|'amber'|'jade'|'tally' })

// 圆角胶囊状态。
Pill({ tone?: 'faint'|'amber'|'jade'|'tally', children })

// 图标按钮（行内动作，默认低调，悬停才实心）。
IconBtn({ label, title?, tone?, onClick, children })

// 标量读数：值 + 单位 + 标签，等宽数字。
Stat({ value, unit?, label, tone? })

// 空状态：一句话 + 一个动作，**不许**再放说明段落。
Empty({ icon?, title, action? })

// 悬停/点击展开的说明层。用来把"设计说明书"收起来。
Hint({ label, children, inline?, align?, maxWidth? })
//  ★ 非 inline 的弹层用 position:fixed + 打开时量一次坐标：它活在很多
//    overflow:auto/hidden 的容器里（右栏、滚动卡片），绝对定位会被裁掉。
//  ★ 同一时刻**只允许一个**弹层；点别处 / Esc / 滚动都会收起。
```

`Panel` 的 `tone` 负责映射到 `.iv-s1/.iv-s2/.iv-s3`，子元素不需要知道阴影。

## 8. 各屏幕的结构目标

### 页头（`90-panel.js`）

```
┌ [记号] 模拟面试间 · 字节 · 高级后端工程师      ● running 考点 5/14   [准备|面试中|报告|设置]  ◐  新建面试 ┐
```
- 左侧：**品牌记号**（SVG，卷宗折角 + 一道声波，24px）+ 产品名 + 当前会话标题（衬线）。
- 移除常驻的「简历 + JD → 一场有准备的面试」副标题与常驻路径行。
- 卷宗库路径收进一个 `Meta` 芯片（`title=` 给出完整路径与理由），点击可浏览——
  `AGENTS.md §3` 要求「界面必须能回答数据在哪」，**不是**要求它永远占两行。
- 页签改成**有滑动指示器**的分段控件（`.iv-tab[data-on]` + 一条 2px 指示条）。
- 主题切换用图标按钮（◐ / ◑，按当前明暗变字形），不写「亮色/暗色」四个字；
  勾了「跟随 DSH 主题」时它淡下去并改为解释原因（见下面「主题」）。

### 提醒条（全局，`90-panel.js`）
- **浮层，不占布局。** 外层是一个零高度的托盘（在页头之后），提醒条按内容收窄、
  水平居中、盖在内容之上。上一版把它当正常 flex 行插在页头下，每弹一条整页就往下跳
  一次——用户感受到的是「页面大幅抖动」。
- 成功/信息 4 秒后**先淡出、再卸载**；失败（`error`）与带动作的常驻，
  带一个关闭 ×（失败必须给出路，`AGENTS.md §7`）。
- 层叠顺序在弹窗（120）之上：保存成功的「已保存」是在放大窗口里发生的，
  压在遮罩下面就等于没提示。

### 左栏（场次）
- 组头：**公司** + 场数（`Meta`），整行可点击**折叠/展开**（chevron 旋转）。
  为什么按公司而不是「公司 · 岗位」：左栏只有 244px，后者必然被截断，
  截断之后公司和岗位都认不出，那行字就白占了。
- 行：标题（**去掉与组头重复的公司前缀**）+ 一行 meta（岗位 · 考点 5/14；
  标题里已经包含岗位就不再重复）+ 行尾一枚 **26px 的「⋯」**。
- 标题被省略号截断时，`title=` 悬停给出完整标题——原生浮框不会被侧栏的
  滚动容器裁掉。
- 「归档/删除」在「⋯」里，**不许压住标题**。上一版把它们绝对定位在行尾，
  悬停时正好盖在省略号上——用户第一眼看到的就是「按钮把字盖住了」。
  现在「⋯」占固定宽度（不跳动、不遮挡、触屏也点得到），点开是一个
  浮起的小菜单（`S.surface('stage')` + `elev-4`），点别处 / Esc 收起。
- 选中的那一行是**抬起来的一张纸**（`--iv-surface-2` + `elev-1`），不是涂深的一格。
- 空列表：`Empty` + 「新建面试」。

### 主题：默认亮色，可跟随 DSH
- **默认亮色**（白面 + 灰缝 + 暖影）；暗色留给夜里用的人。`readTheme()` 的
  fallback 就是 `'light'`。
- 设置页「外观」里有一个 **跟随 DSH 主题** 的开关。勾上之后：
  明暗完全由宿主决定（读 `:root` 的 `color-scheme`，见 `hostColorScheme()`），
  用 `MutationObserver` 跟住宿主的切换（**不轮询**）；页头的 ◐ 按钮视觉上淡下去，
  点它会弹一句「主题在跟随 DSH，去设置页取消」——**不真 disable**，
  真 disable 的按钮点不动，也就没法解释「为什么点了没反应」。
- 取消跟随会回到用户自己选的那一套（选择一直留在 localStorage 里）。

### 准备页（`80-views.js`）
- 「这场面试」标题行删除副标题；公司/岗位/标题三格保留，保存按钮在行尾。
  **元信息只认显式写入**：插件不从 JD 猜（占位值 `新建公司 2026-11-17` /
  `新建岗位 2026-11-17` 在输入框里显示为空，例子进 placeholder）；
  留空保存 = 服务端写回占位值。助手用 `interview_prepare` 改，走同一条归一化。
- 简历/JD 卡片：标题 + 字数 + 简历库计数（下拉）+ **一张纸面预览**。
  **卡片上没有【放大】【修改】【存进简历库】**：点纸面就放大；编辑、上传、
  入库全在放大窗口里完成。卡片只回答「这里有什么」。
- 放大窗口（`MaterialDialog`）：
  - **占满可用高度**：`height: min(88vh, 940px)` + `max-height: calc(100vh - 40px)`，
    宽度 `min(1080px, 100%)`——它是阅读/编辑一整份材料的地方，不是一个小弹层。
    只给 `max-height` 不给 `height`，卡片只会长到内容那么高，宽屏上就是「缩成一小坨」。
  - **预览**（默认）：md 渲染，与卡片同一套排版；
  - **编辑**：保真纯源码（等宽），有改动才出现【保存】；
  - **受保护**：有未保存改动时，点遮罩 / Esc / 关闭都不关窗，顶部浮出
    黄色警告「请先保存变更内容后再关闭！」，并给「放弃修改」这条出路；
  - **上传**：文件先读进草稿（进编辑态），点保存才落盘——上传不等于归档。
- 保存分流：
  - JD：直接保存（一个职位一份 JD）；
  - 简历：问「覆盖原简历 / 存为新简历 / 保存到这场」；首次保存（这一场还没有简历）
    先引导入库并命名，同时留「只存这场」。
- 简历库：下拉弹层，**整行就是「选用」**（标题 + `字数 · 日期`，本场有标记），
  删除是单独一个 ×；不再出现会折行的「用这份」文字按钮。
  「把这场简历存进库」也收在弹层里，不占常驻版面。
- JD 上传只收 `.txt / .md`（客户端挡扩展名，Host 挡文件头）。
- 底稿卡片：默认收起；展开后是清单，收起时只留 `考点 5/14` 与「→ 进入面试中」。
  删除「底稿共 14 项，已问 5 项。面试中助手按它动态深挖……」整段。
- 岗位档案卡片：每行 = 岗位名 + `14 考点 · 1 场` + 「继承」；删除顶部说明。
- 流程脊（FlowSpine）：保留，但改成更细的仪表条——点 + 连线 + `meta` 标签，
  当前步用琥珀呼吸点。

### 面试中（`80-views.js`）
- 舞台仍是主位；未接通时是**有设计的暗场**：点阵 + 姓名 monogram（衬线）+ 跳动的电平 + 计时。
- 提问压在下三分之一（衬线、琥珀竖线）——**这一块是全场最亮的元素**。
- 右栏顶部从「设备 / 声音 / 识别 / 播报」四行说明，压成一条**状态条**：
  `[● 麦克风] [○ 摄像头] [识别 浏览器] [播报 系统音色]` —— 每项一个 `Pill`，
  点开才看 `Hint` 详情（谁的错、怎么改）。
  - 侧栏展开时右栏只有 ~396px，`Hint` 弹层必须 **fixed 浮出容器**（不能被右栏
    的 `overflow` 截断）；
  - 四个「？」**同时只允许一个**打开，点别处 / Esc / 滚动收起——上一版能四个
    一起挂着、互相堆叠。
- 回答框：删除 placeholder 里那句「提交后进入速记，成为事后分析的事实来源」，
  只留「说话或打字」（4–6 字）。
- 转录：行距收紧一点，问/答用一个 `Meta` 前缀区分，时间戳右对齐等宽。

### 报告页
- 阅读版式：`display` 衬线大标题 + 正文 13.5/1.85；统计用 `Stat` 一行。
- 未生成时的空状态：一句原因 + 一个动作（「让助手写报告」）。

### 设置页（`81-settings.js`，语音配置闭环，见 §9）
- 分区：**语音识别**、**语音播报**、**摄像头**、**录像与录音**、**面试间保护**、**环境**。
- 每一区只有三样东西：当前生效值（一行）、可改的控件、一个**测试**按钮。
- 「环境」区保留只读事实（路径、登记状态、模型目录），但用 `Panel` + 表格化对齐。

## 9. 语音配置闭环（第二条需求）

**结论先写**：不依赖宿主模型是对的，这条路要走通，必须给出「**配 → 存 → 测 → 用**」
四条腿，每一条都在界面里看得见。设计见 `docs/VOICE.md`（由语音链负责人落）。

界面契约（设置页语音区）：

```
语音识别
  现在用    浏览器 Web Speech            （Meta 行；来源与理由可点开）
  ─────────────────────────────────
  服务      [自动 | 宿主 | 服务端 · OpenAI 兼容 | 服务端 · MiniMax | 只用浏览器 | 关闭]
  端点      https://api.siliconflow.cn/v1        （留空用该服务默认）
  模型      FunAudioLLM/SenseVoiceSmall
  语言      zh
  凭据      [选择已有 ▾]  已配置 · 来自宿主凭据                 [替换…] [清除]
  ─────────────────────────────────
  [测试识别]   ← 录 2 秒，回显识别结果、走的链路、耗时
```

- **密钥永不回显**：界面只显示 `已配置 / 未配置` 与来源（宿主凭据 / 环境变量 / 插件配置）。
- **密钥不写进插件设置文件**：走宿主 `ctx.credentials.set(ref, value)`，
  ref 名沿用标准环境变量名（`MIMO_API_KEY` 等），与 DSH 生态一致，写进去立刻生效、无需重启。
- **发现已有凭据**：扫描 profile 的 `cordis.patch.yml` 里的 `apiKeyEnv:` + 常见候选名，
  逐个 `credentials.describe(ref)`，把「这台机器上已经有哪几把钥匙」列出来给用户选。
- **测试必须真跑**：识别=录 2 秒真音频跑一遍；播报=合成一句话并在面板里播。
  失败要给出**具体的原因**（HTTP 码、超时、缺凭据、协议不匹配），并说明下一步能做什么。
