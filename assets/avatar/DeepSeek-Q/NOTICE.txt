这张图上做了什么处理（可复现）
----------------------------------------------------------------
  1. 裁到头肩并补成正方形（750×750）：渲染器按 min 比例铺图，宽图会被
     压到底部；正方形才能让脸稳稳居中。顺带把两只猫耳完整框进来。
  2. 白底用 grabCut 抠掉：白外套和白底同一色系，色值阈值会把外套一起切掉
     （所以用 grabCut 的统计模型，不用阈值）。
  3. **把张开的嘴补成皮肤、画一条闭嘴的微笑唇线**——面试官要说话，口型由
     运行时着色器画，底图上不能是张开的嘴。补嘴用 inpaint（周围是脸颊皮肤），
     唇线是 4 倍超采样画的。
  4. 眼睛的锚点与 24 点椭圆轮廓按实测像素坐标给死（左眼 487,432；右眼
     652,378；嘴 591,477，原图坐标）。
  5. 底图的眼窝自己重做：流水线默认的补脸在这种高光很亮的脸上会填成一片
     白雾，眨眼时整块露出来。做法是「base 与原图的差异」定位洞，再拿洞外
     一圈皮肤做归一化模糊填回去。

运行时
----------------------------------------------------------------
  ../vendor/mesh-avatar.js（MIT, © Yuki Shindo），许可见
  ../vendor/LICENSE-mesh-avatar.txt。

绑定：用 RuiC-2D（MIT）的作者工具链在本地跑出来，**运行时不依赖它**；
      不带头部切片（workspace.regions = []），插件不用切片，切了反而有缝。

再生成一份
----------------------------------------------------------------
  node dev/make-avatar.mjs <图片.png> <形象id> \
    --left x,y --right x,y --mouth x,y [--name "面试官 · 某某"]
  （需要本地有 RuiC-2D 与 Python；产物进 assets/avatar/<id>/，
    设置页下拉自动多一项。本目录的两个脚本是这张图专用的版本，
    换图要重新量锚点。）

  **跑本目录的脚本不用先删任何东西。** 工程目录名带时间戳
  （projects/avatar-<id>-<时间戳>），跑完自动清掉同前缀的旧工程；
  上游样例 `da-fei-yu-1` 不受影响（流水线硬依赖它，缺了会直接崩）。
  中间产物落在工作目录（%TEMP%\dsh-avatar-work，或 AVATAR_WORK_DIR），
  不落在脚本旁边——脚本随包发布，在它旁边写文件会把仓库弄脏。

  两步走：
    python source/prep.py         # 抠图 + 裁剪 + 闭嘴 → 工作目录的 square.png
    python source/build_avatar.py # 绑定 + 补眼窝 + 写清单 → RuiC 工程目录
